# Decisions Log

Append-only record of architectural and design decisions.

2026-09-07 | Gemini 3.8 Flash | Decision: Pull EuroSAT Sentinel-2 starter kernel via Kaggle CLI | Why: Provides reference baseline implementation and data preprocessing pipelines for EuroSAT dataset | Alternatives considered: Writing EuroSAT pipeline from scratch without inspecting Kaggle starter.
2026-09-07 | Gemini 3.8 Flash | Decision: Configure Kaggle access token via ~/.kaggle/access_token and KAGGLE_API_TOKEN | Why: Kaggle's new token format (KGAT_*) uses ~/.kaggle/access_token / KAGGLE_API_TOKEN rather than legacy username/key in kaggle.json | Alternatives considered: Legacy kaggle.json format.
2026-09-07 | Gemini 3.8 Flash | Decision: Use raoofnaushad/eurosat-sentinel2-dataset (RGB EuroSAT) for initial baseline | Why: Fast 93.5MB download containing all 27,000 images in 10 classes, enabling rapid baseline iteration before scaling to 2.2GB multi-spectral TIFFs | Alternatives considered: apollo2506/eurosat-dataset (2.2GB 13-band TIFFs).
2026-09-07 | Gemini 3.8 Flash | Decision: Build modular PyTorch classification pipeline (dataset, model, train, evaluate) with ResNet-18 | Why: Industry standard for computer vision baseline; proven ~95%+ accuracy on EuroSAT; fast training and low VRAM footprint on RTX 3050 | Alternatives considered: Custom shallow CNN (poor transfer learning accuracy), Vision Transformer (much slower training).
2026-09-07 | Claude Opus 4.6 | Decision: Use cu126 index instead of cu124 for PyTorch CUDA install | Why: Python 3.14 wheels are only available on the cu126 index; cu124 returns "no matching distribution" for cp314 | Alternatives considered: Downgrading Python to 3.12 (disruptive).
2026-09-07 | Claude Opus 4.6 | Decision: Resize images to 224×224 for ResNet-18 transfer learning | Why: ResNet-18 was pretrained on 224×224 ImageNet images; feeding 64×64 into pretrained conv filters drastically reduces feature extraction quality | Alternatives considered: Keeping 64×64 (faster but weaker accuracy).
2026-09-07 | Gemini 3.8 Flash | Decision: Use inverse-frequency class weighting in CrossEntropyLoss | Why: Mitigates class imbalance penalty for classes like Pasture (2,000 samples) vs AnnualCrop/Forest (3,000 samples) | Alternatives considered: WeightedRandomSampler (adds epoch overhead and complexity).
2026-09-07 | Gemini 3.8 Flash | Decision: Cache get_device() console logging to output device selection once | Why: Prevents repeated device printouts from cluttering CLI prediction outputs and JSON reports | Alternatives considered: Python standard logging (adds config overhead).
